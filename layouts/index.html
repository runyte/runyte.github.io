Close it. Open it again.

In mux mode you're back where you left off. All terminals and AI agents keep doing what they were.

Agents, if you let them.

The MCP server gives agents optional access to your panes. :agent-channel lets them talk to each other.

Keys you already know.

Many keybindings have aliases and will feel familiar to both Helix and Vim users.

Install Runyte.

curl -fsSL https://raw.githubusercontent.com/runyte/runyte/main/install.sh | sh -s -- --desktop

Linux and macOS. Then run runyte --window.

curl -fsSL https://raw.githubusercontent.com/runyte/runyte/main/install.sh | sh

Linux and macOS. On Windows, use the x86-64 ZIP.
