## Markdown

Press `?` to read a formatted page. Press it again to edit the source.

{{< feature-video src="videos/features/markdown.mp4" poster="videos/features/markdown-poster.webp" duration="14.33" caption="Switch a release plan between source and rendered view." >}}

## Finder

Find files, buffers, and terminals with `Space f`. Press Tab to search their contents.

{{< feature-video src="videos/features/finder.mp4" poster="videos/features/finder-poster.webp" duration="13.8" caption="Find a file, then search text across files and terminal output." >}}

## Navigator

Press `Space n` to switch between open buffers and terminals. Type to narrow the list.

{{< feature-video src="videos/features/navigator.mp4" poster="videos/features/navigator-poster.webp" duration="18.13" caption="Visit a file and a running terminal. Return to the same list." >}}

## Session management

Press `Space Space` to manage sessions. Switch with `Shift Left` and `Shift Right`.
Each session keeps its layout and theme.

{{< feature-video src="videos/features/session-management.mp4" poster="videos/features/session-management-poster.webp" duration="22.07" caption="Open the session manager. Switch between API in terafox and Website in ember-dark." >}}

Recorded in Runyte 0.3.3. Each clip uses a different view or theme.

## More tools

| Tool | What it does |
| --- | --- |
| Terminals and agents | Run shells and coding agents beside your files. Edit prompts with `Ctrl-g`. |
| Language tools | Tree-sitter highlighting. Diagnostics, formatting, and navigation through LSP. |
| Persistent sessions | Detach and return to running terminals and unsaved buffers. |
| Completion | Complete words from open buffers and paths from your project. |
| Images and links | Paste images with `Ctrl-v` or `Alt-v`. Follow links with `gf`. |
| Plugins | Add tools written in any language. |
