# Runyte documentation

[Install Runyte](/installation/) on Linux, macOS, or Windows, then run `:tutorial`
inside the editor for an interactive introduction. `Space ?` opens contextual
help, and `:help` opens the complete manual.

## Website controls {#website}

Use the top links, or navigate with the keyboard:

| Input | Action |
| --- | --- |
| `Space ?` | Website help and shortcut settings |
| `Space n` | Find a page |
| `:help` | Open documentation |
| `:about` | Return to About |
| `:demo` | Watch the demo |
| `:github` / `:repository` | Open the source repository |
| `Esc` | Close a dialog or cancel a sequence |

Press keys in sequence. Run commands with Enter.
